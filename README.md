# QI Guide Hub

A mobile-friendly static website for two Forge of Empires Quantum Incursions settlement guides.

## Publish on GitHub Pages

1. Upload all files and the `images` folder to the root of your repository.
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. Wait for the published site link to appear.

Guide images retain the original author credits. Please ensure you have permission to republish source material publicly.
